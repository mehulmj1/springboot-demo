# Spring Boot Demo

Basic Spring Boot REST API project.

## Technologies

- Java 17
- Spring Boot 3.5.6
- Spring Web
- Maven

## Run

```bash
mvn spring-boot:run
```

## API

GET http://localhost:8080/hello

Response:

```text
Hello, Spring Boot!
```
